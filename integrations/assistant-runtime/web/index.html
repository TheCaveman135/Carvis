Voice

How Carvis speaks — manner, not facts. This never changes what it reports happened, only how it says it.

Memory

What Carvis has learned about you, and what it is bound by. A house rule is a standing instruction it may not break — "never turn a bedroom light on after 22:00". A preference shapes how it acts — sleep hours, how you like to be spoken to. A fact is looked up when relevant. Rules and preferences are in front of Carvis on every single turn; facts only when they match. Anything tagged Carvis it wrote on its own; delete freely. Anything tagged you is yours — Carvis cannot edit or remove it.

Voice & glasses

A connected physical Carvis core takes priority when chosen. Choosing a speaker makes that media player available to Carvis for voice output. It does not change your other entity selections.

Speech to text

Transcribes what the glasses hear. Costs money per utterance and the audio leaves this Mac — muting the glasses stops capture at the source, so nothing is sent while muted. Deepgram and AssemblyAI can both have a key saved at once, so switching the engine below is instant — useful for comparing the two on the same real speech.

Deepgram: deepgram.com → Console → API Keys. AssemblyAI: assemblyai.com → dashboard → API Keys.

Web search

Lets Carvis look things up on the live web — news, prices, anything time-sensitive or outside what a model already knows — via Gemini's Google Search grounding.

Get a key at aistudio.google.com → Get API key.

Project Atlas

Reads work unauthenticated once one of these answers. Writing needs a token, which Carvis reads from the macOS Keychain — store one with atlas token set. It is never copied into config.json. Atlas is a home-network box; add a Tailscale address here once it has one, or it will only answer while this Mac is on the home network or the SSH tunnel is up.

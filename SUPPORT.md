# Support

Start with the [README](README.md) and the guides for
[Home Assistant](docs/integrations-home-assistant.md),
[assistant integrations](docs/integrations-assistant.md),
[TV control](docs/integrations-apple-tv.md), and
[Even Realities glasses](docs/integrations-even-realities.md).

For a reproducible problem, open a [bug report](https://github.com/TheCaveman135/Carvis/issues/new/choose).
Use the feature request template for new behavior. For setup questions, open
an issue and describe what you expected, what you saw, and the relevant
Carvis and Node.js versions.

Remove tokens, passwords, transcripts, private URLs, entity IDs, camera
images, and other home details from screenshots and logs before posting.
Report vulnerabilities through the [private security channel](SECURITY.md).
